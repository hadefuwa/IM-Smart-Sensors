Note: All sensors are mounted on the IM4330 bench rig training panel — this is not an external process plant. All IO-Link cables are point-to-point M12 3-wire (24V, 0V, IO-Link data on one unshielded cable per IEC 61131-9). The dashed ISA bubble (XAL-401) indicates a write-only actuator — no process variable is returned. ISDU acyclic read/write is available on all ports via REST: POST /api/io-link/port/{n}/parameter/read and /write.
