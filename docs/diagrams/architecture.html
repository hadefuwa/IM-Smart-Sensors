Data flow: sensors connect to the IFM AL1350 through IO-Link M12 ports. The AL1350 communicates over the 192.168.7.x Ethernet network to the Raspberry Pi 4. Mosquitto receives the 500 ms MQTT updates, FastAPI serves live WebSocket data, and Chromium runs the touchscreen kiosk interface.
